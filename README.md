# Notepad Clone – Python Tkinter

A desktop-based Notepad Clone developed using **Python and Tkinter**. The application provides a simple text-editing interface with file management, text formatting, search functionality, and other useful editing features.

## Features

- **Tabbed Editing:** Work with multiple text documents using tabs.
- **File Operations:** Create new files, open existing files, save files, and use Save As.
- **Text Editing:** Undo, redo, cut, copy, paste, and select all.
- **Text Formatting:** Bold, italic, underline, and strikethrough.
- **Find and Replace:** Search for text and replace matching content.
- **Word Wrap:** Enable or disable word wrapping.
- **Zoom:** Increase or decrease the text size.
- **Date and Time:** Insert the current date and time into a document.
- **Status Bar:** View line number, column number, word count, character count, and line count.
- **Autosave Recovery:** Recover supported unsaved editing sessions using local autosave files.

## Requirements

- Python 3.x
- Tkinter (usually included with standard Python installations)

No third-party Python packages are required based on the current implementation.

## How to Run

1. Install Python 3.x if it is not already installed.
2. Download or clone this repository.
3. Open a terminal or command prompt in the project directory.
4. Run the application:

```bash
python notepad_clone.py
```

On some systems, you may need to use:

```bash
python3 notepad_clone.py
```
